## 3. Sprint 2 Video (2-Minute Walkthrough)

* **Video Title:** `CSQP - Sprint 2 Full Feature Showcase & Final Demo (2-Minute Demo)`
* **File Location / Link:** Uploaded to project repository / Google Drive submission folder.
* **Duration:** 02:00

### Storyboard & Timestamps:
* **0:00 – 0:30 | Question Bank & Quiz Assembly (`CSQP-19`, `CSQP-20` - Krishna):**
  * Instructor uploads bulk questions via CSV import (`POST /api/questions/import`).
  * Creates a timed quiz using random question sampling from the approved pool (`/instructor/create-quiz`).
* **0:30 – 1:05 | Timed Quiz Attempt, Anti-Cheat & Auto-Grading (`CSQP-21`, `CSQP-22`, `CSQP-23`, `CSQP-24` - John & Krishna):**
  * Student starts the quiz; shows countdown timer with automatic submit on expiration.
  * Demonstrates anti-cheat: tab-switching / clipboard lock warnings and single-session lock blocking concurrent logins (`409 Conflict`).
  * Submits quiz and receives instantaneous auto-graded score (0–100%) with response summary.
* **1:05 – 1:35 | Analytics, Leaderboard & PDF Report Export (`CSQP-27`, `CSQP-28`, `CSQP-29`, `CSQP-30` - Harshith):**
  * Student visits **My Progress** to inspect score trends and topic mastery.
  * Demonstrates **Leaderboard** opt-in toggle (`CSQP-29`) honoring privacy preferences.
  * Instructor reviews **Class Analytics** and exports PDF scorecard generated by Python FastAPI service.
* **1:35 – 2:00 | Security Audit, Uptime & Accessibility (`CSQP-33`, `CSQP-35`, `CSQP-36` - Harshith & John):**
  * Admin inspects **Audit Log** (`/admin/audit`) and **99.5% Uptime Report** (`/admin/uptime`).
  * Demonstrates WCAG 2.1 AA keyboard navigation and screen-reader accessibility.
